# STAGGER DIGITAL MOTORSPORT
### Stagger-v0.0.3057a

This is an unofficial publication of Stagger-v0.0.3057a. I uploaded this in the wake of the discord server seemingly disappearing and limited information regarding the situation online, other than the fact the owners account was hacked.

Whilst this file is CLEAN and is the OFFICIAL version downloaded from the SDM discord server, I accept no responsibility for any damage or unexpected changes to your device or hardware. As with anything on the internet, use your own judgement when downloading files.

# TUTORIAL:

 - Extract 'Stagger-v0.0.3057a.RAR'
 - Run Play Stagger.bat
 - It will take anywhere from 7-20minutes when first launching the game for the shaders to load, this is normal. It will be significantly quicker from here-on.

# TO INSTALL MODS:
- You can use any NR2003 mod, and most BeamNG & Assetto Corsa mods with this game, simply drag them into the appropriate folder in '/mods'
- Either re-launch the game or use the RESCAN feature in the games MOD page
